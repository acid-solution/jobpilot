# JobPilot 前端与交互

现行实现核对日期：2026-10-17。页面为 React + TypeScript + Vite，当前业务数据来自 API；原型阶段的模拟状态不代表现行数据来源。

## 页面与导航

[导航定义](../frontend/src/navigation.ts)包括工作台、市场画像、用户画像、项目推荐、知识短板、学习路线、设置。当前目标贯穿业务上下文，切换时不能混入旧目标的请求结果。

| 页面 | 主要任务 |
| --- | --- |
| 工作台 | 解释当前进度、缺项和下一步 |
| 市场画像 | 原始材料识别、候选选择、JD 详情与能力要求 |
| 用户画像 | 必要信息、经历材料、能力依据和评估 |
| 项目推荐 | 推荐比较、参考仓库、项目选择与重新核对 |
| 知识短板 | 综合能力差距、能力验证与复习 |
| 学习路线 | 准备清单、预算、两份计划预览及导入 |
| 设置 | 模型配置、用量和相关账号入口 |

## 视觉与结构

桌面使用左侧导航、顶部当前目标与中间业务内容。蓝灰主色、浅灰背景、白色面板及轻量边框；图标使用 Lucide。窄屏收拢导航，浮动助手优先保证消息和确认区域可读。

视觉约定用于保持一致性，不在本文重复每个业务字段；产品规则见[产品说明](REBUILD_PRD.md)。

## 招聘材料处理

粘贴允许网页杂讯和多岗位。排队与识别通过进度弹窗展示真实状态；后台继续后可从入口重新打开。关闭提示不终止后台任务，同标签页刷新不反复弹出相同阶段提示。

多候选默认不选，先看原文再确认。无有效 JD 与技术失败分别展示；失败保留重试、原文和上次结果。旧规则成功结果提供主动重分析入口，刷新页面不自动付费重跑。

市场页共享一次 JD 列表读取，活动任务按返回建议轮询，页面重获可见性或焦点时重读。旧请求不能覆盖新状态。搜索和状态筛选从已加载列表派生，不额外发起资料请求。详见 [JD 专项](JD_IMPORT.md)。

## 资料、就绪与报告

前后端使用同一套就绪规则。条件不足时显示缺失内容及入口；前置读取失败时暂停生成，不把未知当作条件满足。

材料先提取文字、核对后分析。能力列表显示已确认标准名称与依据；未审核候选只显示数量，未评估不显示为 L0。报告重新生成时保留旧结果，并区分旧依据与新状态。

正式验证与复习是不同业务模式。页面的进度、草稿与提交状态由共享会话控制逻辑恢复，失败、刷新或切换目标后不能冒用过期会话。

## Agent 浮窗

浮窗可移动、收起、恢复、切换和删除会话；每个会话绑定创建时的目标。模型消息、工具过程、引用和业务确认分开呈现，不展示隐藏推理。

写操作卡片显示具体影响范围，只有本次确认后执行。记忆建议有独立确认流程，不阻塞普通对话。遗忘、旧回答标记与长期偏好见[上下文说明](AGENT_CONTEXT_MEMORY.md)。

## 学习路线

未就绪时显示准备清单，保留既有路线为只读预览。项目和知识分别设置投入与推进方式，页面校验不是后端校验的替代。

确认导入显示固定内容和对应计划；待核实状态保留同一请求。回执链接打开 StudyFlow 后仍要正常登录，并主动激活草稿。见[路线说明](LEARNING_ROUTES.md)。

## 开发与验证

[前端 package.json](../frontend/package.json)维护开发、测试、类型检查和构建命令。单元测试与浏览器假接口测试检查状态和交互，不能代替真实模型质量验收。命令及可选线上脚本见[验证指南](VALIDATION.md)。
