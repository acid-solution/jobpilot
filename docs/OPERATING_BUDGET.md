# JobPilot 运行预算边界

本文保留 2026-09-10 确认的求职展示预算作为历史规划，按 2026-10-17 的实现补充费用来源。它不是付款台账，也不说明当前服务器购买价格、余额或账户权益。

## 原定支出范围

首年规划上限为 500 元，原预留如下：

| 项目 | 历史预留 |
| --- | ---: |
| 服务器与数据库运行 | 100 元 |
| 域名 | 80 元 |
| 业务模型调用 | 150 元 |
| 邮件验证码 | 5 元 |
| 自动备份 | 当时暂未预留 |
| 机动余量 | 150 元 |
| 合计 | 485 元 |

这些数值是分配额度，不是最新报价或已发生支出，不要求全部充值。编码助手订阅、人工和推广不包含在这份业务预算中。实际支出另行记录，不从部署成功或模型调用次数推算。

## 当前费用来源

- 固定资源：服务器、存储、带宽、域名和异机备份。
- 用户调用：材料分析、问答、推荐、路线、助手和按需摘要。
- 平台调用：目录审核、岗位判级及百炼向量。
- 认证邮件：取决于 shared-auth 实际发送服务与使用量。

用户自己的任务使用其 Key，平台任务使用平台凭据；开发者调试也可能同时涉及两种承担方。费用统计边界见[模型用量](MODEL_USAGE.md)。

## 运行与控制

现有联合部署包含两业务服务、共享认证、PostgreSQL、MySQL、Redis 和 Caddy。资源需求应按这套实际拓扑测量，不能继续把早期 JobPilot 单服务预算视为已验证容量。

Worker 并发、目录审核额度和模型开关由服务端配置控制。历史默认值不是对外承诺的吞吐或免费额度。观察模型调用与实际内存、磁盘、备份体积后再调整。

发布脚本已有发布前业务库备份；这与按周期自动备份、异机保存和恢复演练不同，见[发布与恢复](../deploy/CICD.md)。

## 维护方式

服务器活动、邮件与模型单价不在本文件复制成“当前价格”。购买和调整预算时重新核对供应商官方条件；未核实前保持未知，不延用旧折扣假设。

扩大试用范围或预计超出原预算时，应依据实际测量重新决定投入。本文不授权购买、充值或更换服务。
