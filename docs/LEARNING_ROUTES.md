# 学习路线与 StudyFlow 导入

核对日期：2026-10-17。JobPilot 保存规划，StudyFlow 保存执行。选择推荐项目不会自动生成路线，路线导入不会自动激活计划。

## 使用流程

1. 在学习路线页核对市场、用户画像、审核判级及当前项目选择。条件不齐显示准备清单；读取失败暂停新生成和导入，已有路线只读保留。
2. 分别填写项目实践与知识准备的周预算，合计不超过个人每周总投入；各自选择日期或课时模式，沿用期望周期。
3. 主动生成两份计划。阶段有成果，任务有行动、预计分钟和完成标准；组合要求只选足够路径，无必备差距时安排复习与验证。
4. 编辑预览并保存，校验周期、预算、数量和修订。顺序调整只提示前置关系，不建立跨计划执行锁，预算不足不自动延长周期。
5. 核对固定内容并确认导入，取得真实回执后打开 StudyFlow。
6. 正常登录 StudyFlow，查看草稿并主动激活。

等级变化自动刷新知识准备摘要，不调用模型、不更换项目。点击更新知识计划才生成新知识任务，项目计划保持原样；新内容仍要重新确认导入。

## 版本与角色

一个学习路线包包含 `project` 和 `knowledge` 两类计划。JobPilot 的路线版本与 StudyFlow 两份计划版本各自编号。

首次导入创建目标、两份计划和两份草稿；后续只为内容变化的角色增加草稿，不覆盖原任务、计时或改期。已有草稿返回冲突，需用户先激活或取消。

已导入路线的编辑创建新路线版本；未导入草案由修订号防止并发覆盖。结果待核实时不能悄悄改写载荷。

## 服务配置

先部署支持令牌交换的 shared-auth 和支持路线导入的 StudyFlow，再开启 `LEARNING_ROUTES_ENABLED=true`。路线 Worker 复用每类 `WORKER_COUNT`，默认 2。

| 配置 | 含义 |
| --- | --- |
| `AUTH_EXCHANGE_URL` | 认证的 `/auth/v1/token/exchange` |
| `JOBPILOT_EXCHANGE_SECRET` | 与认证一致的至少 32 字符服务凭据 |
| `STUDYFLOW_MCP_URL` | 与两服务 `STUDYFLOW_MCP_RESOURCE` 完全相同 |
| `STUDYFLOW_WEB_URL` | 浏览器登录与查看草稿的地址 |

三项导入配置全部为空时可以只启用规划；配置不完整不能假装导入可用。正常生产使用 HTTPS，回环开发或显式 HTTP 联调见[联合部署](../deploy/JOINT_DEPLOYMENT.md)。

## 生成与发布

路线生成使用用户 DeepSeek 配置和带输出限制的结构化接口，当前上限为 8,000 输出 token。任务持久化，使用租约、心跳与恢复。

发布前在账号锁内核验完整输入、目标和版本。生成失败保留旧路线。推荐的项目依据与实时知识摘要分别管理；岗位要求、经历或投入改变时需重新核对项目，而等级变化不自动更换选题。

## 导入事务与权限

确认先在本地事务冻结载荷、摘要与幂等键，提交后换取短期令牌并调用 MCP，网络期间不持有账号锁。后续资料变化不改写在途请求。

代办令牌绑定用户、MCP 受众、导入键、内容摘要与有限权限，最多两分钟且不超过源访问令牌期限。它不进入模型、前端、日志或路线存储；不能用于 StudyFlow 普通 API，也不是浏览器单点登录。

只有匹配真实回执才显示成功。超时或断线显示待核实，用同键查询和重试；不能把未知当失败后另建重复计划。任务完成不产生能力升级，也不持续自动调用模型重规划。

## 接口与验证

接口前缀 `/api/v1/learning-route`：

| 操作 | 方法与相对路径 |
| --- | --- |
| 读取路线、就绪、知识摘要 | `GET /` |
| 生成 | `POST /generate` |
| 编辑草案 | `PATCH /draft` |
| 确认导入 | `POST /import` |
| 重试已确认导入 | `POST /imports/:id/retry` |

方法以[路由注册](../backend/internal/httpapi/learning_routes.go)为准。导入反向契约见 StudyFlow 文档，核验入口见[验证指南](VALIDATION.md)。
