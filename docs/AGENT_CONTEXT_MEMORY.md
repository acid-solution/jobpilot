# Agent 上下文与长期偏好

## 使用规则

助手使用四类内容：近期完整轮次、会话摘要、已确认长期偏好、通过业务工具读取的当前资料。摘要只属于同一会话；跨会话只读取确认过的偏好和正式业务状态，不支持任意历史会话语义检索。

浮窗的脑形按钮打开记忆管理，可保存、修改和遗忘。支持项目语言、排除项目类型、项目架构、学习方式和回答详略。前四项默认限当前目标，回答详略全局适用。等级、每周预算、项目选择与业务授权不属于偏好，仍由原功能管理。

助手可在正常回答时提出最多三项记忆建议，来自本轮用户自己的表述。建议尚未生效，不阻塞聊天。用户可以确认、编辑后确认或拒绝。修改和确认带版本及哈希，过期请求返回 409；重复确认读取原结果，不重复写入。

已确认偏好用于之后主动发起的项目推荐与路线生成。本次明确调整意见优先并作为生成依据保存，不修改长期偏好。偏好变化不使旧报告过期，不更换已选项目，不改写路线或已导入版本。只更新知识计划时只读取学习偏好，保留项目任务。

## 遗忘和删除

遗忘保留聊天原文，但受影响范围此前的模型上下文停止使用。当前目标的遗忘只重置本目标；全局偏好的遗忘重置全部目标。其他有效偏好与最新业务资料继续可查。

旧摘要、旧建议、外置结果和迟到响应受上下文纪元约束，不能复活偏好。尚未确认的旧业务动作失效；已经接受并冻结的外部导入仍按原请求执行或核实回执。

删除会话清除摘要、轮次、外置结果和相关建议，独立确认的偏好保留。偏好保留短引文，源消息删除后不再提供消息链接。遗忘同时清除该偏好的历史值，仅留下版本及防恢复标记。

旧报告可供用户查看的“生成时偏好”不会被改写；Agent 业务读取会去掉这组历史偏好字段，避免重新载入为当前记忆。

## 持久化与一致性

- 消息序号在数据库内原子分配，历史按 `created_at,id` 确定性回填。对话展示分页与模型历史读取互相独立。
- 一轮从用户消息开始，包含业务确认和恢复，记录资料依赖与偏好指纹。原工具文字不会被伪装成完整 ToolCall 协议历史。
- 摘要为约束、讨论状态、问题及来源 ID 的结构化列表。当前等级、预算、项目选择由业务库决定。缺少依赖元数据的历史助手分析不冒充当前事实。
- 生成摘要不持有数据库事务。发布时取得账号锁，校验会话租约、摘要修订、目标、纪元、资料版本和原消息来源。
- 摘要失败不推进覆盖位置，使用仍有效摘要和近期完整轮次降级，并提示早期内容未完整带入。必要内容超预算则报错，不截断本次问题或待确认参数。
- 回复的最终校验、保存与轮次状态在同一账号事务内完成。业务修改与后台更新沿用相同锁和单调资源版本，A→B→A 也会识别为变化。
- 恢复检查点先检查纪元与依赖；确认参数和真实回执仍由原动作机制保存，记忆不产生授权。

长期偏好使用与业务报告一致的语义目标签名；旧会话及动作保留原作用域，通过服务适配，不强行改写无法识别的历史目标。

## 配置和工具预算

以下配置在后端进程启动时读取；默认模型窗口是保守配置，不代表供应商当前全部模型窗口。

| 环境变量 | 默认值 |
|---|---:|
| AGENT_CONTEXT_ENABLED | true |
| AGENT_MEMORY_ENABLED | true |
| AGENT_CONTEXT_MODEL_WINDOW_TOKENS | 65536 |
| AGENT_CONTEXT_INPUT_MAX_TOKENS | 48000 |
| AGENT_CONTEXT_COMPACT_AT_TOKENS | 32000 |
| AGENT_CONTEXT_RECENT_TOKENS | 8000 |
| AGENT_CONTEXT_SUMMARY_MAX_TOKENS | 2500 |
| AGENT_CONTEXT_OUTPUT_RESERVE_TOKENS | 4096 |
| AGENT_CONTEXT_SAFETY_TOKENS | 8192 |
| AGENT_CONTEXT_ARTIFACT_TTL | 168h |

启动时检查预算关系。每次 Eino 模型调用都计算消息、系统规则、工具 Schema 与协议开销。没有匹配 tokenizer 时，使用 UTF-8 字节和协议开销保守估算，不视作供应商精确 token；账本始终采用真实 usage。

每次发送最多生成一次持久化摘要；特别长的历史分段推进，不能越过尚未处理的部分。降级近期窗口会显式提示，不宣称已经完整回忆。关闭摘要后仍执行遗忘和资料版本保护。

长只读结果先保存完整内容，再返回预览和引用；`read_context_artifact` 按账号、目标、会话、纪元和资料版本分页读取。失效或到期需重新查询。Eino reduction 保留最近完整工具轮次，排除业务写工具、确认参数和记忆建议。过期临时结果在恢复循环中分批清理。

## 接口

所有接口使用现有身份认证；目标范围由后端构造。写接口校验预期修订和内容哈希。

- `GET/POST /api/v1/agent/memories`：读取或主动保存。
- `PATCH/DELETE /api/v1/agent/memories/:id`：修改或遗忘。
- `GET /api/v1/agent/memory-proposals`：读取当前目标待确认建议。
- `POST /api/v1/agent/memory-proposals/:id/resolve`：确认、编辑后确认或拒绝。
- `GET /api/v1/agent/conversations/:id/messages?before_sequence=N`：读取较早消息。

SSE 增加 `context`、`context_invalidated` 和 `memory_proposal`。刷新后从数据库恢复建议和业务动作。摘要进度不含隐藏推理。

## 验证与评测

普通 Go 测试覆盖白名单、预算、来源、确认、遗忘、账号和目标隔离、超过 200 条消息、CAS、旧租约、外置结果权限、真实 Eino 工具调用与账本。数据库测试使用 `JOBPILOT_ADMIN_DATABASE_URL` 创建和销毁独立数据库，不清理业务库。

真实评测入口：`TestLiveAgentContextEvaluation`。显式配置 `RUN_AGENT_CONTEXT_LIVE_TEST=1`、`MODEL_USAGE_TEST_USER` 与后端进程配置，另提供临时数据库管理连接。只发送合成材料，使用选定账号的现有用户 Key，并在其正常账本记录调用。`AGENT_CONTEXT_EVAL_OUTPUT` 只保存案例、模式、正确性、错误、耗时和 token，不保存提示词、回答或凭证。

用例共 30 个，分为长对话、跨会话、更新、遗忘、未知和讨论状态；前 10 个分别重复三次，三种模式共 150 次运行。模式是原最近 12 条、相同预算的近期窗口和分层方案。这里是项目自建的合成评测，不是 LongMemEval 官方成绩，也不能代替真实业务人工评审；模型错误或工具错误必须单独统计。

独立页面验收入口 `TestAgentMemoryBrowserFixture` 需显式开关，仅挂载原 Agent 浮窗、使用合成数据和临时数据库，不绕过任何真实账号登录。

## 发布与回退

启动自动执行迁移 40–41；不扫描旧聊天自动建立偏好，不在迁移中付费生成摘要。部署 Compose 已提供同名预算参数，修改后重建或重新创建 API 服务使环境变量生效。

摘要和额外调用均使用用户 Key，归入该次 Agent 功能用量。压缩可能增加请求、影响缓存命中，不能承诺降低总费用。先观察事实正确性、遗忘隔离和任务成功率，再比较 token 与延迟。

回退可关闭新摘要或偏好消费，但保留上下文仓储、纪元及版本检查，不能恢复旧的无过滤历史注入。不要回滚数据库迁移清除已确认偏好或防恢复标记。

## 2026-10-15 实测记录

已运行 Go 全量测试、独立 PostgreSQL 集成测试、相关 race 检查、`go vet`、前端生产构建及 Compose 配置校验。页面通过原浮窗组件和真实接口验证“建议不阻塞聊天 → 编辑后确认 → 查看偏好 → 确认遗忘”；仅使用一次性数据库的合成数据，未修改正式账号偏好。

真实模型使用专用测试账号现有用户 Key，场景与原文均为合成内容。三种模式各运行 50 次（30 个场景，前 10 个重复三次）。初次结果如下，错误也计入分母：

| 模式 | 符合预期回答 | 工具错误 | 实际 HTTP 调用数 | 输入 token | 输出 token | 累计耗时 |
|---|---:|---:|---:|---:|---:|---:|
| 最近 12 条 | 9/50 | 12 | 74 | 185691 | 11084 | 227.1 秒 |
| 预算内近期窗口 | 10/50 | 7 | 64 | 233914 | 12133 | 214.5 秒 |
| 分层上下文 | 45/50 | 5 | 97 | 489657 | 14504 | 312.6 秒 |

初次运行发现“无目标时查询推荐会中断工具链”的问题。修复后只重查这 24 次错误运行：最近 12 条为 6/12、近期窗口为 5/7、分层为 5/5，均无工具错误。其余运行没有重复付费。初始数据和复测数据分别保存于 [评测元数据](evaluations/agent-context-20261015.json)，不能拼接成一次全新的无偏评测成绩。

评分检查合成问题的预期短答案；本轮没有评估完整学习规划质量、复杂业务任务完成率或一般性事实正确率。这组场景刻意覆盖会丢出窗口的早期限制和跨会话偏好，因此不能外推为通用能力提升，也不是 LongMemEval 官方成绩。分层模式包含额外摘要调用，本次输入 token 和累计延迟更高；真实供应商用量已进入模型账本，没有按文字长度补算费用。

修复项还有：JSON 模式摘要提示词显式声明 JSON；确认写入后移除旧观察而保留真实回执；超长消息单独保存分段游标；摘要发布同时检查修订与原覆盖位置；遗忘前的迟到摘要、结果和检查点不得恢复旧上下文。页面为过期或缺少版本依据的历史回答显示提示。
