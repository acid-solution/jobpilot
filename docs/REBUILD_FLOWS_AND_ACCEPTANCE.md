# JobPilot 页面流程与验收

核对日期：2026-10-17。使用隔离测试账号与合成材料，按以下可见结果核验。每项独立记录环境和结果；本清单本身不表示已经运行通过。

## 账号与配置

1. 用两个测试账号分别登录，保存不同目标和材料。
2. 检查切换账号后不能读取另一人的资料、会话、模型用量。
3. 保存、替换、删除用户模型配置，页面只返回遮盖元数据。
4. 无 Key、错误 Key 和供应商故障分别显示真实原因。

依据：[认证](SHARED_AUTH_SERVICE.md)、[开发配置](DEVELOPMENT.md)。

## 招聘材料与 JD

| 输入或动作 | 预期可见结果 |
| --- | --- |
| 带导航和广告的单岗位材料 | 识别并导入独立 JD，保留原文 |
| 多岗位材料 | 默认不选，逐项核对后确认 |
| 小说、简历或无招聘内容 | 空结果提醒，不创建正式 JD |
| 模型调用失败 | 保留材料与重试，不显示为已判定无效 |
| 编辑 JD 识别出多个候选 | 只能选择一项更新原 ID |
| 重复确认 | 返回已有结果，不重复创建 |
| 删除后主动重新提交 | 可以重新导入，不因删除自动重建 |
| 关闭进度弹窗并切页 | 后台继续，能够重新查看状态 |
| 规则更新后查看旧成功结果 | 提示主动重新分析，不因刷新自动调用模型 |

检查提取、分类、归一化、审核与判级各自结果。分类失败不抹掉已提取要求；能力判级失败不撤销合法能力。完整边界见 [JD 处理](JD_IMPORT.md)。

## 能力与画像

- MySQL 索引、事务以细项保留，不创建两个独立能力。
- MySQL、PostgreSQL、Redis 保留不同产品。
- 同义别名与范围归属分别处理，细项不得自动成为公共别名。
- 任选、至少 N 项和加分条件保留原始关系，未审核名称不进入公开列表。
- 有效 JD 仍需满足当前目标关系才能计入；不足 10 份解释采集缺口。
- 采集完成但审核/判级未完成时，不误报分析就绪。
- 未评估与明确 L0 分开，已满足任选路径后不强迫评完所有候选。

样例与当前失败记录见[粒度契约](ABILITY_GRANULARITY_PROMPTS.md)、[评测记录](JD_PARSING_EVALUATION.md)。

## 个人材料与问答

1. 提取文字后先核对，再确认用于能力分析。
2. 检查材料、等级、必要信息的保存和重登恢复。
3. 初始评估、下一档能力验证、复习使用正确模式。
4. 复习不改等级，正式验证结果需要用户确认。
5. 刷新、退出、失败恢复和切换能力后不使用过期问答会话。

## 报告与项目选择

前置不齐显示缺项；前置读取失败暂停生成。生成失败保留旧报告。检查原文、用户依据、市场等级及组合要求，不以综合等级猜测细项诊断。

推荐比较项目设想和真实可核查仓库。重新推荐后选择必须属于可用结果；资料变化后重新核对选择依据。等级变化不自动更换当前项目。

## Agent 与记忆

- 只读工具查询当前账号、目标的真实资料。
- 写卡片取消不执行，确认成功后有真实回执。
- 修改依赖资料后旧确认失效，重复确认不再次执行。
- 记忆建议未确认不生效；确认、编辑、拒绝独立于业务动作。
- 遗忘后旧摘要、迟到响应和建议不能恢复偏好；删除会话不删除独立偏好。
- 工具错误、模型错误和业务拒绝分别显示。

## 学习路线与跨系统闭环

1. 选择项目，满足准备清单，设置两份预算和模式。
2. 生成、编辑并保存两份计划，核对总预算与周期。
3. 确认导入固定内容；网络结果不明显示待核实。
4. 同键重试返回相同回执，不能另建重复计划。
5. 在 StudyFlow 登录并主动激活草稿。
6. 更新知识计划，只为变化计划新增草稿，项目执行进度保留。
7. 导入不自动激活、完成任务或改变能力等级。

配置及事务边界见[学习路线](LEARNING_ROUTES.md)。

[验证指南](VALIDATION.md)列出可重复命令。浏览器假接口测试验证界面状态，真实数据库测试验证事务与隔离，真实模型评测验证指定样本质量，线上验收验证实际配置；记录时分别注明。
