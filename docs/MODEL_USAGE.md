# 模型用量与估算费用

在设置页打开“模型用量”。默认日期范围为上海时区最近 30 个自然日，可筛选功能及费用承担方，查看功能操作和调用明细。一次功能可能包含多次 DeepSeek 请求、重试及百炼向量化请求。无模型调用的操作显示零次调用。

## 统计含义

- 输入 token 已包含缓存命中部分，不再把缓存量额外加到输入中。缓存命中率只使用具有可信缓存数据的输入样本。
- 百炼向量化的供应商总 token 作为输入用量，输出和缓存为“不适用”。
- 用户 Key 与关联平台 Key 分开统计。目录审核可能由多位用户共享，每人按调用 ID 去重；共享平台费用不能跨账号相加。无个人关联的全局目录向量化不展示在个人页面。
- 供应商请求完成不代表 JD 或报告分析成功。无效模型内容、解析错误及过期 Worker 丢弃结果，仍有真实模型消耗。
- 请求已发送但用量缺失、断线或未成功回写时显示“待核实”，不代表零消耗。不会为了补统计重新调用模型。
- 历史审核和判级只回填已有可信 token 信息，不恢复缓存或历史单价。旧失败记录无法确认实际发送时不计入已确认调用次数。
- 启用账本之前未保存的调用和逐次重试无法补齐，历史统计不完整；不会用文字长度推算 token。

## 单价配置

复制 `backend/config/model-pricing.example.json` 到自己的配置路径，在服务端设置 `MODEL_PRICING_FILE`，填写核实后的单价并重启。文件无密钥，可按部署方式管理；单价必须是十进制字符串，单位为每百万 token。

以下仅示范格式，数值为测试示例，**不是供应商现行报价**：

```json
{
  "version": "example-test-rates",
  "prices": [
    {
      "provider": "deepseek",
      "model": "供应商实际返回的模型名称",
      "currency": "CNY",
      "input_per_million": "1",
      "cache_hit_per_million": "0.1",
      "output_per_million": "2"
    },
    {
      "provider": "bailian",
      "model": "text-embedding-v4",
      "currency": "USD",
      "input_per_million": "0.5",
      "cache_hit_per_million": "0",
      "output_per_million": "0"
    }
  ]
}
```

模型按供应商与**返回模型名称**精确匹配，不把未知模型套用另一模型价格。支持 CNY、USD，分币种汇总，不换汇。每次调用保存适用价格快照，后续修改单价不会更改旧费用。缓存单价不同但供应商缺少缓存明细时，不能算出可信费用。

费用仅按配置单价估算，不计算赠送额度、折扣、峰谷优惠或税费；不是实际扣款。存在未知费用时汇总标注“已知部分估算”，未知金额不当作零元。

## 保存与访问边界

调用账本仅保存请求标识、时间、模型、结果、token 和价格等元数据，不保存 API Key、认证头、完整提示词或回复正文。调用前记录失败会阻止发送；供应商用量回写独立于业务结果事务。平台审核原有额度规则继续生效，统计不会重复扣额度。

接口 `/api/v1/model-usage/summary`、`operations`、`calls` 均只读，只查询当前账号可访问的关联记录。筛选参数为 `from`、`to`（包含结束日期）、`purpose`、`payer`、`operation_id`，明细支持 `page`、`page_size`，每页最多 100 条，日期范围最多一年。

StudyFlow 接收学习计划不产生模型调用，本页面只统计 JobPilot 的模型请求。
