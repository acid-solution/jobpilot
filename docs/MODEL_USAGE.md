# 模型用量与估算费用

核对日期：2026-10-17。设置页默认查询上海时区最近 30 个自然日，按功能、承担方、操作与逐次调用查看。业务执行成功与供应商已经产生消耗是两件事。

## 统计口径

| 项目 | 含义 |
| --- | --- |
| 一次调用 | 一次实际 HTTP 模型请求，重试另记 |
| 一次功能操作 | 可关联多次生成、纠正、摘要与向量调用 |
| 输入 token | 包含缓存命中部分，不能再把缓存加一遍 |
| 百炼向量 | 供应商总 token 记为输入，输出/缓存为不适用 |
| 用户用量 | 使用用户 Key 的调用 |
| 关联平台用量 | 与当前资料关联的平台调用，可能跨账号共享 |
| 待核实 | 已发送但缺可信 usage 或回写，不能记为免费 |
| 无调用操作 | 不生成虚构 token，不为补统计再次请求模型 |

每位用户按调用 ID 去重，共享平台用量不能跨账号简单相加。无个人关联的全局目录向量不进入个人页面。

模型内容无效、解析失败、发布过期或旧 Worker 结果被丢弃都可能已产生消耗。账本启用前的逐次重试、历史缓存及单价无法可靠补齐，历史统计存在缺口。

## 价格配置

使用[价格示例](../backend/config/model-pricing.example.json)创建版本化文件，填写实际核对过的单价，再设置 `MODEL_PRICING_FILE` 并重启。单价为十进制字符串，单位每百万 token；示例数值不代表供应商现行报价。

按供应商和实际返回模型名称精确匹配。未知模型不套用其他型号价格。支持 CNY、USD，分币种汇总，不自动换汇。每次调用保存价格快照，改配置不重算旧费用。

供应商没有缓存明细而缓存价不同，或价格缺失时，相关费用为未知；汇总只展示已知部分，不能把未知当零元。估算不包含赠额、折扣、税费或供应商结算调整。

## 保存与访问

账本保存请求标识、模型、时间、结果、token、价格和关联元数据，不保存 Key、认证头、完整提示词或回复正文。调用前无法记录时阻止发送，usage 回写独立于业务发布事务。已有平台额度控制不因统计重复扣减。

接口均位于 `/api/v1/model-usage`：
`GET /summary`、`GET /operations`、`GET /calls`。仅查询当前账号可访问记录。

筛选包括 `from`、`to`（包含结束日）、`purpose`、`payer`、`operation_id`；明细分页为 `page`、`page_size`，最多每页 100 条、日期范围最多一年。

## 摘要与跨系统

会话摘要使用用户 DeepSeek Key，归入本次 Agent 功能。偏好建议复用当前调用；确认、修改与遗忘偏好不调用模型。

上下文预算是输入估计，供应商 usage 才是用量事实。压缩可能增加摘要请求或改变缓存命中，不承诺省钱。StudyFlow 接收计划本身不产生模型调用。

当前实现见 [modelusage](../backend/internal/modelusage)、[用量持久化](../backend/internal/storage/postgres/model_usage_repository.go)。验证范围见[验证指南](VALIDATION.md)。
