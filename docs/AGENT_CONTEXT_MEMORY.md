# Agent 上下文与长期偏好

现行规则核对日期：2026-10-17。工具与写操作确认见[Agent 说明](AGENT_DESIGN.md)，本页维护上下文、偏好和遗忘的边界。

## 哪些内容可以进入回答

| 来源 | 作用与限制 |
| --- | --- |
| 近期完整轮次 | 保留用户消息、相关工具和业务确认，不把原工具文字伪装成 ToolCall 历史 |
| 会话摘要 | 当前会话较早的约束、讨论状态、问题与来源，不充当业务事实 |
| 已确认长期偏好 | 明确作用域下跨会话沿用的稳定偏好 |
| 业务查询与观察 | 读取当前版本的等级、预算、项目和其他正式资料 |

跨会话不任意检索历史聊天。每个会话绑定目标；当前资料来自业务服务，不能让摘要覆盖数据库。历史回答缺少可靠版本依据时提示可能过期。

## 偏好的保存与使用

记忆入口可新增、修改和遗忘偏好。当前支持项目语言、排除类型、项目架构、学习方式及回答详略；前四项默认限当前目标，详略全局适用。等级、预算、项目选择和业务授权不属于偏好。

助手每次最多提出三条来自本轮用户表述的建议。建议不阻塞聊天、不自动生效；用户确认、编辑后确认或拒绝。修订号与哈希保护过期请求，重复确认返回原回执。

推荐与路线在之后的主动生成中使用当前偏好；本次明确调整意见优先，但不修改长期值。改偏好不使旧报告过期、不更换选题、不改写已导入计划。仅更新知识计划时不改变项目计划。

## 遗忘与会话删除

遗忘保留聊天原文，但停止把对应范围此前的上下文用于模型。目标偏好遗忘重置本目标，全局偏好遗忘影响全部目标。摘要、建议、外置结果和迟到响应受纪元保护，不能恢复旧偏好。

尚未确认的旧动作失效；已经接受并冻结的外部导入继续按固定内容执行或核实回执。记忆不提供业务授权。

删除会话清除该会话的摘要、轮次、外置结果与相关建议，独立确认偏好保留。当前偏好只保留当前值及必要来源，已处理建议清空旧值和前后预览；不提供偏好历史恢复。报告的“生成时偏好”保留为历史依据，Agent 读取时排除，不再注入为当前偏好。

## 摘要与并发

摘要生成不持有业务事务。发布时在账号锁内校验会话租约、摘要修订、覆盖位置、目标、遗忘纪元、资料版本和来源。最终回复保存也需同一受保护范围内核验；A→B→A 仍视为变化。

一次发送最多生成一次持久化摘要，超长历史分段推进。失败不推进覆盖位置，退回仍有效摘要与近期完整轮次并提示缺失；必要输入超预算时报错，不截断本次问题或待确认参数。

长只读结果保存完整内容后返回预览，`read_context_artifact` 按账号、目标、会话、纪元及版本分页读取。失效需重新查询。Eino reduction 不压缩业务写工具、确认参数和记忆建议。

## 配置

所有值启动时读取，单位为估算 token 的项目不是供应商真实 usage，也不宣称是供应商最新模型窗口。

| 配置 | 默认 |
| --- | ---: |
| `AGENT_CONTEXT_ENABLED` | true |
| `AGENT_MEMORY_ENABLED` | true |
| `AGENT_CONTEXT_MODEL_WINDOW_TOKENS` | 65536 |
| `AGENT_CONTEXT_INPUT_MAX_TOKENS` | 48000 |
| `AGENT_CONTEXT_COMPACT_AT_TOKENS` | 32000 |
| `AGENT_CONTEXT_RECENT_TOKENS` | 8000 |
| `AGENT_CONTEXT_SUMMARY_MAX_TOKENS` | 2500 |
| `AGENT_CONTEXT_OUTPUT_RESERVE_TOKENS` | 4096 |
| `AGENT_CONTEXT_SAFETY_TOKENS` | 8192 |
| `AGENT_CONTEXT_ARTIFACT_TTL` | 168h |

启动校验预算关系，每次模型调用估算系统规则、消息、工具 Schema 和协议开销。没有匹配 tokenizer 时采用保守估计。关闭摘要仍执行遗忘、纪元与资料版本检查。

摘要使用用户 Key，归入本次 Agent 用量；确认、编辑、遗忘偏好不调用模型。摘要可能增加调用与延迟，不能把压缩比写成省钱比例。

## 接口与发布

接口位于 `/api/v1/agent`，使用普通身份；写接口校验预期修订与哈希。

| 操作 | 路径 |
| --- | --- |
| 查询/主动保存偏好 | `GET/POST /memories` |
| 修改/遗忘 | `PATCH/DELETE /memories/:id` |
| 查询建议 | `GET /memory-proposals` |
| 处理建议 | `POST /memory-proposals/:id/resolve` |
| 读取较早消息 | `GET /conversations/:id/messages?before_sequence=N` |

SSE 中 `context`、`context_invalidated`、`memory_proposal` 表达公开状态。刷新从数据库恢复动作与建议，不公开隐藏推理。

迁移 40–42 建立上下文、摘要和当前偏好机制，迁移 42 清理旧偏好修订及已处理建议副本。回退可停止摘要或偏好消费，仍保留防恢复机制；数据库回滚无法恢复已清理历史值，不应删除遗忘标记。

## 验证记录

以下保留 2026-10-15 的实测范围与结果，文档重写没有重新运行模型评测。完整原始元数据见[评测元数据](evaluations/agent-context-20261015.json)。

已运行 Go 全量测试、独立 PostgreSQL 集成测试、相关 race 检查、`go vet`、前端生产构建及 Compose 配置校验。页面通过原浮窗组件和真实接口验证“建议不阻塞聊天 → 编辑后确认 → 查看偏好 → 确认遗忘”；仅使用一次性数据库的合成数据，未修改正式账号偏好。

真实模型使用专用测试账号现有用户 Key，场景与原文均为合成内容。三种模式各运行 50 次（30 个场景，前 10 个重复三次）。初次结果如下，错误也计入分母：

| 模式 | 符合预期回答 | 工具错误 | 实际 HTTP 调用数 | 输入 token | 输出 token | 累计耗时 |
|---|---:|---:|---:|---:|---:|---:|
| 最近 12 条 | 9/50 | 12 | 74 | 185691 | 11084 | 227.1 秒 |
| 预算内近期窗口 | 10/50 | 7 | 64 | 233914 | 12133 | 214.5 秒 |
| 分层上下文 | 45/50 | 5 | 97 | 489657 | 14504 | 312.6 秒 |

初次运行发现“无目标时查询推荐会中断工具链”的问题。修复后只重查这 24 次错误运行：最近 12 条为 6/12、近期窗口为 5/7、分层为 5/5，均无工具错误。其余运行没有重复付费。初始数据和复测数据分别保存于 [评测元数据](evaluations/agent-context-20261015.json)，不能拼接成一次全新的无偏评测成绩。

评分检查合成问题的预期短答案；本轮没有评估完整学习规划质量、复杂业务任务完成率或一般性事实正确率。这组场景刻意覆盖会丢出窗口的早期限制和跨会话偏好，因此不能外推为通用能力提升，也不是 LongMemEval 官方成绩。分层模式包含额外摘要调用，本次输入 token 和累计延迟更高；真实供应商用量已进入模型账本，没有按文字长度补算费用。

修复项还有：JSON 模式摘要提示词显式声明 JSON；确认写入后移除旧观察而保留真实回执；超长消息单独保存分段游标；摘要发布同时检查修订与原覆盖位置；遗忘前的迟到摘要、结果和检查点不得恢复旧上下文。页面为过期或缺少版本依据的历史回答显示提示。
