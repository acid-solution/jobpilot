# JobPilot 能力等级参考

按已确认的尺度编写 · 2026 年 9 月 10 日

这份文档为首批 77 项能力补齐 L0–L5 的具体说明，供模型解读 JD、评估用户材料、生成补充问答，以及用户自行设置水平时参考。等级尺度和 MySQL、Agent 开发两个示例已经确认，其余说明按同样尺度整理为初稿。

## 怎样使用

每项能力只评一个综合等级。表中的任务描述帮助判断整体水平，不拆成多个知识点分数，也不要求逐句打勾。用户需要评估哪些能力，仍由当前目标的相关 JD 决定，整份目录不是每个人都要完成的清单。

| 等级 | 通用含义 |
| --- | --- |
| L0 | 未学习 |
| L1 | 了解概念 |
| L2 | 能在指导下完成基础任务 |
| L3 | 能独立完成常见任务 |
| L4 | 能处理复杂场景并作出技术取舍 |
| L5 | 能设计体系并指导他人 |

材料不足以判断时显示“待评估”，不直接记为 L0。模型先使用简历和经历中的依据，再按需求文档约定补充问答；用户可以自行设置或修改等级。

“独立完成”允许查阅文档和使用开发工具，重点是能够解释、修改并验证自己的工作。等级不直接对应工作年限或职位名称，L5 也不是所有求职者的准备目标。岗位要求和用户当前水平分别判断，不因为 JD 要求较高就改变用户等级。

## 维护这份参考时

等级说明描述的是能力表现，具体技术版本和 API 用法以相应官方文档为准。后续可以结合实际 JD、用户材料和问答结果调整不清楚的措辞；涉及能力范围或等级含义的变化，需要按需求文档约定处理已有评估，不能直接把旧等级套到含义改变的能力上。

例如 ArkTS 的语言能力与 HarmonyOS 的应用开发能力分别保留，参考 [OpenHarmony 的 ArkTS 介绍](https://github.com/openharmony/docs/blob/master/en/application-dev/quick-start/arkts-get-started.md)区分语言和应用开发语境。类似地，框架使用、编程语言与理论基础可以共享材料依据，各自的等级仍分别判断。
